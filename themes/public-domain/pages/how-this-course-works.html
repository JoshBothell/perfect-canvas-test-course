How This Course Works

Each unit module follows the same rhythm:

  1. 📖 Learn: read the unit guide and reference pages.
  2. ✍️ Practice: submit status memos and research (assignments).
  3. 💬 Discuss: argue cases with other students.
  4. 📝 Assess: take the unit quiz. A passing score unlocks the next unit.

Late Work

Late submissions lose 10% per day, but never drop below 50% of earned points. Missing work is not automatically penalized.
