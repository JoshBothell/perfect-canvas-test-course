# Public Domain Academy: provenance of every non-generated asset

This theme is meant for **commercial** use, so every asset that isn't generated by `theme.py` has a recorded public-domain or CC0 basis. This file is not copied into the course.

## Catalog images (386 artworks)

- **What:** one open-access image per work in `data/collection.csv`, fetched at build time from the row's `image_url` and cached in `build/cache/pd-open-access/`.
- **Sources:** both museums release images of public-domain works under **CC0 1.0**.
  - **Art Institute of Chicago** API (`source = aic`): only works with `is_public_domain: true`. All API fields are CC0 *except* `description` (CC-BY 4.0), which the curation script never requests or stores. Images come from AIC's IIIF server at 843px.
  - **The Metropolitan Museum of Art** Collection API (`source = met`): only objects with `isPublicDomain: true` (Open Access, CC0).
- **Evidence:**
  - Every CSV row records the source id, the object page, the image URL, the licence + licence URL, the PD flag field and the retrieval date.
  - `data/provenance.jsonl` holds the CC0 API fields (including the PD flag) each row was built from.
  - The Full Collection page and the shipped `data/collection.csv` show this evidence inside the course.
- **Selection:** made by `tools/curate_catalog.py` (one-time, networked).
  - Unique titles of 60 characters or fewer; generic titles are dropped.
  - Subjects/terms that are unsuitable for client demos are filtered out.
  - Any title or artist that matches a non-commercial theme's terms (`cc validate --forbid-theme`) is dropped.
  - Re-running it may pick different works; the committed CSV is the source of truth.
- **Credit:** CC0 needs no attribution, but the welcome page gives a courtesy credit with "no endorsement implied". Don't use either museum's name or logo in a way that implies endorsement.

## Deliberately avoided

- Creative Commons and Public Domain Mark **logos**, which are trademarks. The status badges are original text badges.
- Characters with live trademark or special-rights claims in the roster: Sherlock Holmes, Tarzan / John Carter, Winnie-the-Pooh, Mickey Mouse, Peter Pan.
- OpenStreetMap embeds (ODbL, requires attribution) and Wikimedia images whose licence isn't PD/CC0.
